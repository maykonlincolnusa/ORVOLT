# Contracts

`proto/` is the authoritative, versioned ORVOLT wire-contract source. The implemented namespaces are `orvolt.telemetry.evse.v1` and `orvolt.energy.site.v1`. Reserved namespaces are documented for events, commands, and edge health.

Run `buf generate` from the repository root to regenerate Go bindings. Rust bindings are generated by `prost-build` from the same source during the edge build. Generated output is not edited by hand.

Compatibility is enforced by `buf breaking` in CI once a main branch baseline is configured.
